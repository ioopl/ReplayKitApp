#  InAppRecordingView

## Record In-App Screen and presents a default video editor preview. This Option is for recording only whats visible in this App screen and saves that as a MP4. 

## Remember: Option A (In-App Screen Recording) is designed to produce a local, fully finished MP4 video file.

## Under the Hood: This option records interface interactions and presents the system's RPPreviewViewController via a SwiftUI representable.


Main files are : InAppRecordingViewModel.swift & InAppRecordingView.swift
